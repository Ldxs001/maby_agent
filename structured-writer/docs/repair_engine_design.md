## 1. 问题分级（定稿）

| 级别 | 意思 | 修法 | 交互 |
|------|------|------|------|
| **T0** | 纯格式（末行编号缺失 / 禁用模式残留） | 代码直改正文 txt | 自动，不弹窗，仅通知 |
| **T1** | 内容问题（17 种：连续性/承诺/逻辑/语义/推理） | **35b 整段重构** | 面板按子结构勾选 |
| **T2** | 推理审核失败（模型异常） | 人工 | 显示指引 |

> T0 只动正文 txt，不碰 state。时间登记/实体状态不在 T0——它们走重构后同步。

## 2. T1 问题清单（17 种）

| 源检 | 问题 |
|------|------|
| 1 连续性 | 时间词无重叠 / 角色名无重叠 |
| 2 承诺链 | 承诺关键词未续接 |
| 4 逻辑 | 角色消失 / 时间回退 / 概述偏离 / 实体关系断裂 |
| 5 语义 | 正文偏离概述 / 语义断裂 / 话题过渡弱 / 情绪偏离 / 语义冗余 / 跨章延续弱 |
| 6 推理 | 因果 / 人格 / 情绪弧 / 对话 / 论证（5 维） |

## 3. 修复流程

### 3.1 两种模式
```
章完结 → 全六检（1-6 含 R1）→ 分级
  ├─【手动模式】弹面板：问题照列 + 下方按章内子结构勾选（勾谁修谁，勾掉=跳过）
  └─【自动模式】（config auto_repair，默认关）→ 有 T1 直接重构，最多 3 轮
  → 逐段重构（35b，配置驱动）→ 同步步骤 → 全六检重检
  → 清零 ✅ / 减少未清零（再来，≤3 轮）/ 没改善 → 回滚
```

## 4. 整段重构契约

```
输入给 35b：原段全文 / 子结构规划 / 上段尾+下段头 100 字 / 该段问题清单
硬约束：保留首行标题、末行编号、别名行；字数 ±15%；不改剧情走向/人物设定；只输出正文
输出校验：标题/末行/别名行存在；字数范围（超限警告）；无思考/无围栏；原子写+备份
```

## 5. 重构后同步步骤（关键）

```
重构落盘后，对每个被重构的子结构：
  ① 实体状态 force 刷新（extract force=True，覆盖式：alive→injured 更新）
  ② 时间线重扫（删该段旧条目 → 重扫新正文时间引用 → 重新登记）
  ③ characters 状态同步（与 entity_tracker 对齐）
```

## 6. 双份备份与回滚（关键）

```
备份（每段重构前）：.backup/S02.txt + .backup/state_round{N}.json（整个 novel_state 快照）
回滚（重检失败/没改善）：恢复正文 + 恢复 state → 正文与状态永远一致
```

## 7. 修复模型（配置驱动）

- 模型 = config `writer_model`（写作配置模型），timeout/max_tokens 全继承
- 复用 `llm_client.py` chat_detailed，零新增配置

## 8. 重检（全六检含 R1）

- 重构完 → 重跑六检（1-6 含 R1，3.5 分钟/段是成本，必须跑）
- 清零 ✅ / 减少未清零 → 再滚（≤3 轮）/ 没改善 → 回滚

## 9. 后端引擎（novel_repair_engine.py）

```
class RepairEngine:
    def run(state_path, chapter, mode="manual", max_rounds=3):
        for round in 1..max_rounds:
            issues = run_all_checks()          # 全六检
            t0s, t1s = classify(issues)
            if not t1s: return success
            if round > 1 and len(t1s) >= prev: rollback(); return fail
            apply_t0(t0s)
            for seg in checked_segments(t1s):  # 勾选或全选
                backup(seg)                    # 正文 + state 快照
                new = rewrite(seg, problems)   # 35b
                if validate(new): write(new); sync_state(seg)  # 同步实体/时间线
            # 重检进入下一轮
```

API：
| 端点 | 功能 |
|------|------|
| `/api/novel/repair/preview` | 章完结后获取分级清单 |
| `/api/novel/repair/apply` | {session, chapter, mode, checked_subs} |
| `/api/novel/repair/rollback` | 回滚正文+state |
| `/api/novel/repair/status` | 进度轮询 |

config 新增：`novel_checks.auto_repair`(false) / `repair_rounds`(3)

## 10. 风险与防范

| 风险 | 防范 |
|------|------|
| 重构引入新问题 | 重检全六检 + 没改善自动回滚 |
| 35b 输出丢格式 | 契约校验 4 项，拒绝落盘保留原稿 |
| 字数缩水 | ±15% 校验，超限警告 |
| 剧情改偏 | prompt 硬约束 + 自动模式默认关 |
| 死循环 | 轮次上限 3 |
| 实体/时间线脱节 | 重构后同步 + 双份回滚 |
| 写段线程并发 | 修复持锁互斥 |

## 11. 实施分期

```
P1: T0 自动修复（末行/禁用模式，纯代码）
P2: RepairEngine + 重构契约 + 35b 调用（配置驱动）→ CLI 可测
P3: UI 面板（preview/apply/rollback/status）+ 手动模式
P4: 自动模式 + 同步步骤 + 双份回滚 + 轮次限制
```
